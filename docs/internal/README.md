# Maintainer documentation

These documents are for contributors and maintainers working from a clone or fork
of the repository. They describe local development, browser verification and
release operations. They are intentionally excluded from the npm package and are
not part of the consumer learning path.

Start with:

- [Development](development.md) for local setup, commands and repository checks;
- [Browser testing and report interpretation](browser-testing.md) for installed
  package smoke tests, reports and benchmarks.

Release maintainers also use:

- [Compatibility evidence](compatibility-evidence.md);
- [Release procedure](release.md);
- [RC1 release record](release-map.md).

Public consumer documentation remains in the parent `docs/` directory.
